# AquaMetric SEO Practice Website

A responsive static English-language product education website for practicing SEO Assistant tasks.

## Pages
- `index.html` — Home
- `products.html` — Product overview
- `guide.html` — Educational article
- `about.html` — Project explanation
- `contact.html` — Demo-only contact form
- `robots.txt` and `sitemap.xml` — technical SEO files
- `assets/css/styles.css` — styles
- `assets/js/main.js` — mobile menu and demo form behavior

## Important
AquaMetric is a fictional demo brand. The contact form does not send or store messages. Do not claim real product specs, customers, rankings, traffic, or inquiries.

## Publish with GitHub Pages
1. Create a public GitHub repository, for example `seo-assistant-project`.
2. Upload all files and folders in this project (not just the ZIP file).
3. In repository Settings → Pages, choose the `main` branch and `/ (root)` folder, then save.
4. Wait for the published URL, commonly `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.
5. Replace every `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY` placeholder in the HTML canonical/Open Graph tags, `robots.txt`, and `sitemap.xml` with your actual site URL.
6. Commit the changes and wait for deployment to update.

If you instead use a custom domain, use that domain consistently for canonical URLs, sitemap, and Open Graph URLs.

## SEO checklist after deployment
- Open every page on desktop and mobile.
- Check all internal links and page titles.
- Open `/robots.txt` and `/sitemap.xml` directly to ensure they load.
- Add the site as a property in Google Search Console and complete ownership verification.
- Submit the sitemap in Search Console.
- Use URL Inspection to request indexing for important pages.
- Remember: submitting a URL does not guarantee indexing or rankings.
- If using GA4, create a property and add the measurement tag only after reviewing Google's instructions and your privacy obligations. This starter project does not include a GA4 ID.
